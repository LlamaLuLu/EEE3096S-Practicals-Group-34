## ⚙️ About the Practicals

This repository contains the practical work for the **Embedded Systems II (EEE3096S)** course. The practicals are designed to:
- Deepen our understanding of embedded microcontroller systems
- Develop skills in writing and debugging low-level code
- Interface with hardware components (e.g., LEDs, buttons, sensors)
- Apply real-time programming concepts using tools like MPLAB X and PIC microcontrollers
